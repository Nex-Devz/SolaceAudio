1.0.32 Latest

15 Nov 2026 1 change

jar · 349 KB Release on GitHub

Fixed1

  • Lavalink LavaLyrics route collision. LyricsController and SolaceLyricsManager now carry @ConditionalOnMissingClass and @ConditionalOnProperty. When lavalyrics-plugin is installed alongside SolaceAudio, the plugin yields the /v4/lyrics endpoints to LavaLyrics instead of throwing a Spring Ambiguous mapping error, while still supplying its multi-provider lyrics (LRCLIB, Deezer, Genius, Spotify) into LavaLyrics.

1.0.31

15 Nov 2026 4 changes

jar · 349 KB Release on GitHub

Added4

  • Audiomack direct audio source. A native AudiomackAudioSourceManager backed by Audiomack's official v1 API with HMAC-SHA1 OAuth 1.0a signing. Supports admsearch: and audiomack: prefixes plus song, album and playlist URLs, and plays signed M4A/MP3 CloudFront streams without an external proxy.
  • Shazam discovery and recognition. A ShazamAudioSourceManager for shsearch:, szsearch: and shazam: queries and track URLs. It pulls title, artist, ISRC and artwork, then delegates playback to the mirror ladder.
  • Expanded provider ladder. admsearch: and shsearch: are registered in TrackResolutionEngine.DEFAULT_PROVIDERS and YouTubeTrack.MIRROR_SOURCES, with recursion-safe self-source loop avoidance.
  • Regression coverage. AudiomackAudioSourceManagerTest and ShazamAudioSourceManagerTest bring the suite to 65 tests.

1.0.30

15 Nov 2026 9 changes

jar · 349 KB Release on GitHub

Fixed4

  • Thread leaks and daemon lifecycle. Schedulers and pools in PoTokenManager, YouTubeProxyHandler and YouTubeSourceManager now run on dedicated SolaceAudio-* daemon thread factories, so a plugin reload or node shutdown no longer hangs the JVM.
  • REST aliases and client casing drift. Multi-path routing on /recommendation and /recommendations, /sponsorblock and /sponsorBlock, removing 404s in client libraries that picked the other spelling.
  • SSRF warning log sanitisation. Rejected cipher URL updates pass through SecurityFilter.sanitize() before logging, blocking CRLF and log injection.
  • Scoring and metadata guard. Strict ISRC prioritisation (1.0 perfect score) and a 30-second duration deviation penalty in CandidateScorer and TrackResolutionEngine.

Added5

  • Amazon Music native MESK engine with CSRF negotiation against music.amazon.com, keeping the proxy as a fallback rather than a hard dependency.
  • Amazon prefixes and mirror integration via azsearch: and amazonsearch:.
  • Spotify TOTP authentication and a sidecar playback hook.
  • Spotify and Deezer in the default ladder, with self-source loop prevention.
  • Test suite at 60 tests with AmazonMusicNativeTest and SpotifyTokenTest.

1.0.29

13 Nov 2026 3 changes

jar · download Release on GitHub

Added3

  • JioSaavn in the priority ladder. jssearch:{query} sits in DEFAULT_PROVIDERS and the config ladder, so a YouTube 429 falls through to JioSaavn's 320 kbps CDN stream instead of ending playback.
  • Apple Music iTunes Store fallback. When storefront token generation or catalog calls fail, search and lookup resolve through the public iTunes API with no authentication.
  • Regression tests. TrackResolutionEngineTest and AppleMusicFallbackTest cover the ladder and the fallback path.
