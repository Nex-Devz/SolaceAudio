# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **SolaceAudio**, please do not open a public issue. Instead, report it privately through one of the following channels:

- **Discord**: Reach out to the maintainers privately in our community: **[discord.gg/devz](https://discord.gg/devz)**
- **Email**: Send details to `inkmcontop@gmail.com`

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact.

We will review and address valid reports promptly.
